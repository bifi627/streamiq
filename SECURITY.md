# Security policy

## Reporting a vulnerability

Report it privately through GitHub's private vulnerability reporting: the repo's
**Security** tab → **Report a vulnerability**
(<https://github.com/bifi627/streamiq/security/advisories/new>).

Never open a public issue, pull request or discussion for a vulnerability: the
repo is public.

Please include what is affected (API, gateway, web app; version or commit), how to
reproduce it, and what an attacker gains.

## What to expect

- A first answer within a week.
- The report stays private while it is being fixed; you hear when the fix ships
  (gateway: a new release, which installed gateways offer as an update).
- Credit in the published advisory, if you want it.

StreamIQ is a one-maintainer project with no bug bounty. Only the latest gateway
release and the hosted service are supported.
